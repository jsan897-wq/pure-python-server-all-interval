📖 1. What is Pure Python Market Server?

The Pure Python Market Server is a lightweight, zero-dependency financial analysis and report generation engine. It replaces the legacy 50 MB Microsoft Excel macro workbook (7vp bn11 -one - Copy.xlsm) and Windows COM (win32com) with a clean, modern Python application.

💡 Key Advantage: Because it contains zero Windows COM dependencies and requires no desktop Microsoft Office, this server can run on any free Linux cloud provider (Render.com, Google Cloud Run, Railway) 24/7 without needing your own personal computer!

❌ Legacy Excel Macro System

Requires Windows OS, desktop Microsoft Excel, 50MB macro workbook, win32com, and an active physical computer running at all times.

✅ Pure Python Server

Runs on Linux, Windows, or macOS. Uses yfinance, pandas, and matplotlib. Generates PDF reports in ~2 seconds.

⚙️ 2. What It Does (Core Pipeline)

Whenever you select a stock, choose your desired time interval and lookback period, and trigger a run, the server performs the following automated steps:

  1. Multi-Timeframe Market Data Ingestion: Supports customizable candle intervals and historical lookback periods for multi-timeframe analysis and predictions:
    • Intervals: 15m (15 Minutes), 30m (30 Minutes - Default), 1h (1 Hour), 1d (Daily), 1wk (Weekly), 1mo (Monthly).
    • Lookback Periods: 5d (5 Days), 1mo (1 Month), 3mo (3 Months), 6mo (6 Months), 1y (1 Year), 2y (2 Years).
    • Smart Handling: For intraday intervals (15m, 30m, 1h), Yahoo Finance provides up to 60 days of historical data; the engine automatically clamps or fetches the maximum available intraday window (~60 days) to prevent empty data errors. For daily/weekly/monthly intervals, full multi-year history (6mo, 1y, 2y) is utilized.
  2. Computes Technical Indicators: Calculates 20-period Simple Moving Average (SMA), 50-period Exponential Moving Average (EMA), and 14-period Relative Strength Index (RSI).
  3. Calculates 16 Sheet10 Price Levels: Recreates the mathematical matrix from Sheet10 (c11, b11, b12, b11 inv, b12 trans, etc.) across the chosen timeframe and computes their spread metrics D(n).
  4. Generates a High-Resolution 3-Page Vector PDF Report: Produces a complete multi-page document matching the Sheet10 layout with dynamic date/time axis formatting:
    • Page 1: OHLC price action with dynamic interval/period titles, moving averages, and 60-point comparison cycle lines (Chart 11 emulation).
    • Page 2: Formatted 16 calculation price levels table with ranks, prices, and spread values.
    • Page 3: Trading volume distribution bars and 14-period RSI oscillator chart scaled to the selected timeframe.

💻 3. How to Run Locally

You can run and test this server on your Windows PC with a single click:

Method A: 1-Click Batch File (Easiest)

In the pure_python_server folder, double-click:

run_local_pure_python.bat

This will start the local server on http://localhost:8080.

Method B: Using Python Command Line

cd "pure_python_server"
pip install -r requirements.txt
python server.py

Then open your web browser and go to:

🚀 Open Local Dashboard (http://localhost:8080)

☁️ 4. How to Deploy Online (Free, 24/7, No Physical PC)

Because this code is 100% Linux native, you can deploy it to free cloud hosting platforms so it stays online 24/7 without needing your PC:

Option 1: Deploy to Render.com (100% Free Web Service)

  1. Upload or push the pure_python_server folder to your GitHub account.
  2. Log in to Render.com and click New + ➔ Web Service.
  3. Connect your GitHub repository.
  4. Configure the service:
    • Runtime: Python 3
    • Build Command: pip install -r requirements.txt
    • Start Command: python server.py
    • Instance Type: Free ($0 / month)
  5. Click Deploy Web Service.
  6. Render will provide a live HTTPS URL (e.g. https://my-stock-report.onrender.com). Anyone can access it from their phone or laptop anytime!

Option 2: Deploy to Google Cloud Run (Free Tier)

Deploy using the included Dockerfile:

cd pure_python_server
gcloud run deploy pure-market-server --source . --allow-unauthenticated

Option 3: Run with Docker

docker build -t pure-market-server .
docker run -p 8080:8080 pure-market-server

🔌 5. REST API Reference

You can also integrate this server into other software, apps, or scripts via simple HTTP API endpoints:

Endpoint Method Description Example Payload / Response
/ GET Serves the web dashboard interface HTML Page
/api/generate POST Fetches candles for the specified interval/period and generates the 3-page PDF report Payload: { "stock": "RELIANCE.NS", "interval": "1d", "period": "1y" }
Response: { "success": true, "stock": "RELIANCE.NS", "interval": "1d", "period": "1y", "candles": 247, "size": 68481, "duration": 2.1 }
/api/download GET Downloads or streams the latest generated PDF application/pdf binary stream
/health GET Health check endpoint for cloud uptime monitoring { "status": "healthy" }
